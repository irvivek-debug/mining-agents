Why this is the only dollar figure here

It is the only one this repository establishes. The Reliability Engineer states it in their own words, and the value tree carries it as the anchor for asset reliability. Every other magnitude — the cost of a stockout, the value of an hour recovered, the price of a deferred shipment — depends on this site's contracts and volumes, which are the client's to supply.

So this deck does not print an ROI it cannot source. Where a number belongs and is not ours to know, it says so, in orange, at a size no one can mistake for a result.
