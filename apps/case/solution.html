The solution

Two patterns, a hundred agents, fifty-two doors.

Not a hundred chatbots. Two composition patterns applied deliberately: a swarm where a question needs several angles argued and then criticised, and a single deep agent where it does not. Every agent is bound at build time to the tables it may read and the tools it may call.

Pattern A

Twelve swarms

A coordinator, three specialists working the same incident from different evidence, and a critic whose whole job is to find what the other four missed. Five agent nodes, one door.

Pattern B

Forty departmental deep agents

One role, one process, one question. Where the answer is a query and a calculation rather than an argument, a swarm is overhead paid five times.
