Underneath both

Personas and the value tree

The Phase 0 spine these screens rest on: docs/personas-and-value-tree.md. It holds the re-rooted CEO tree, eleven personas with jobs-to-be-done traced to named agents, the orphan register, and the assumption ledger.

Read the orphan register before the demo. It is where the honest gaps are, and knowing them is what lets you answer a hard question without improvising.

One rule these artifacts follow
No invented numbers. The only client figure available is the $145k/hr mill downtime rate. Everywhere else a baseline would belong, the screens render [CLIENT INPUT REQUIRED] rather than a plausible-looking number. A fabricated benchmark that gets challenged in the room costs more than an admitted gap.
